# Visual and structural gap reconciliation · V5.0.9.2

Coverage now groups missing drawing labels with their parent picture through original Docling ancestry. One drawing review target retains all related source references; individual labels do not cause duplicate GPU work. Existing authoritative vision entries link to their existing review screen. Pictures with no review route remain visible and link to the original page for reconstruction.

Human-verified decorative/not-useful decisions exclude their picture and nested labels from the recovery queue. The full audit retains these exclusions and the deciding ledger entry. A later machine recommendation never replaces human authority. Unverified decorative recommendations do not exclude source content. Correction-ledger changes invalidate the coverage report.

Missing tables link to matching existing structural routes when present, retaining the table's source identity. An accepted structural route alone is not proof that a missing table is represented in search, so it stays in the gap audit until representation is restored.

This update changes audit classification and review navigation only. It does not dispatch new model jobs, alter human decisions, infer diagram relationships, or apply repairs. Phase 10 still requires review of genuine visual/structural omissions and generated-answer evaluation.
